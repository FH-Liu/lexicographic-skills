# Lexicographic skills

Two complementary skills for source-faithful dictionary work:

| Skill | Purpose |
| --- | --- |
| [lexicographic-import](lexicographic-import/SKILL.md) | Prepare and import scanned or digital dictionaries, preserving source readings, attribution and mappings. |
| [lexicographic-families-and-loans](lexicographic-families-and-loans/SKILL.md) | Search for word families, formal variants and inflections, then assess loans with scoped evidence and confidence. |

Each folder includes its `SKILL.md`, agent metadata and reference materials. Keep both folders together to preserve cross-skill links.

## Use

Place both skill folders in your agent's skills directory. The workflows prepare the whole authorized dictionary or corpus offline before publication, with a central register for decisions, evidence and coverage.

The lexicon-editor adapters require the companion [lexicon-editor repository](https://github.com/FH-Liu/lexicon-editor), including its offline register, schema and guarded publication tools. Those tools and dictionary data are not bundled here. Links to that private repository require access.
