# Tungusic and Mongolic lexicographic skills

| Skill | Use it for |
|---|---|
| [Lexicographic Import](lexicographic-import/SKILL.md) | Prepare a scanned or digital dictionary, choose how special symbols are encoded, and preserve source readings, structure and attribution. |
| [Word Families and Loans](lexicographic-families-and-loans/SKILL.md) | Search for lexical identity, word families and inherited cognacy. Screen for loans when requested. |

Install the two folders together in your agent’s skills directory for the optional handoff from import to analysis. The [special-symbol catalogue](lexicographic-import/references/phonetic-symbols.md) illustrates encoding choices. The [donor catalogues](lexicographic-families-and-loans/references/areal-comparisons.md) provide Chinese and Russian comparison cases. Use the conventions confirmed for the corpus under study.

These packages come from [lexicon-editor revision b8dce7c0d](https://github.com/FH-Liu/lexicon-editor/tree/b8dce7c0d2a63e8cc016b9acf6ad31ed4ad85d45/workflows/shared/skills). Dictionary-specific mappings and editor procedures are maintained in the source repository.
